# Лендинг ЖК «Город-Парк», квартал «Культурный»

Статичный сайт без сборки: открыть `index.html` через любой веб-сервер
(для проверки: `python -m http.server 8765` в этой папке → http://localhost:8765).

## Структура
- `index.html` — вся разметка, 12 блоков по ТЗ, в порядке ТЗ.
- `assets/css/style.css` — стили, mobile first (брейкпоинты 480 / 560 / 768 / 1024 / 1280).
- `assets/js/main.js` — анимации, квиз, формы, модалка, отзывы, карта.
- `assets/js/vendor/` — GSAP 3.13 + ScrollTrigger + SplitText, Lenis 1.3 (Lenis грузится только на десктопе с мышью).
- `assets/fonts/` — Raleway 400/600, Akrobat 300/400 (woff2, латиница + кириллица).
- `assets/img/` — рендеры в webp (960 / 1280 / 1920 и вертикальный кроп для телефона), карта `map.svg`.
  Первый экран на телефоне — тот же рендер, что на десктопе (`facade-street-1280.webp`), он занимает экран над плашкой.

## Карта района
`assets/img/map.svg` собрана из данных OpenStreetMap (дороги, вода, парки, застройка) в цветах бренда, 68 КБ в gzip.
Метки стоят по координатам с Яндекс Карт и OSM (ЖК: 56.849415, 53.320728).
Скрипт расставляет метки под любой размер карты, прячет подписи, которые не помещаются, и рисует дугу-маршрут
до выбранного объекта. Объекты переключаются сами, пока посетитель их не трогает.
Подпись «© участники OpenStreetMap» обязательна по лицензии ODbL — не удалять.

## Формы
Во всех формах есть поля «Имя» и «Телефон», маска +7 (___) ___-__-__ и две галочки:
согласие на обработку данных (обязательное) и согласие на информацию о скидках (необязательное, уходит в заявку как `promo_consent`).
В конце `index.html`, блок `window.GP_CONFIG`:
- `leadEndpoint` — адрес обработчика заявок (POST, JSON). Пока пусто — заявки только пишутся в консоль браузера.
- `metrikaId` — номер счётчика Яндекс.Метрики; цели: `lead_price`, `lead_quiz`, `lead_final`, `click_phone`.

В заявку уходят: тип формы (`price` / `quiz` / `final`), имя, телефон, ответы квиза, UTM-метки и yclid, адрес страницы.

## Хостинг — обязательно
- Включить сжатие brotli или gzip для `html, css, js, svg` (CSS 57 → 11 КБ, JS 174 → 54 КБ).
- Кэш для `assets/*`: `Cache-Control: public, max-age=31536000, immutable`; для `index.html` — `no-cache`.
  При изменении CSS/JS менять номер версии в `index.html` (`style.css?v=2`, `main.js?v=2`).
- HTTP/2 или HTTP/3.
- Для `og:image` указать полный адрес картинки после выбора домена, добавить `<link rel="canonical">`.

## Анимации
- Первый экран появляется на CSS сразу с первой отрисовкой; анимации прокрутки собираются после неё порциями.
- Приёмы LUCE: анимации привязаны к скроллу (scrub), первый экран «проваливается вниз»,
  фото двора «уходит вглубь» и становится карточкой, подчёркивание слов по скроллу,
  плавный скролл только на десктопе, на телефоне без закреплений экрана.
- Бренд: раскрытие двора через знак-тюльпан, органичные «плашки», линейные формы, карта в цветах бренда.
- Интерфейс (ui-motion): кнопка → лоадер → галочка, «жидкие» табы планировок, пружины на CSS.
- `prefers-reduced-motion` учитывается: анимации отключаются, всё видно сразу.
